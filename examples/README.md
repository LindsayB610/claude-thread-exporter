# Example Exports

These are public-safe exports generated by `claude-thread-exporter` from intentionally non-private shared Claude conversations. They exist as stable examples for documentation, visual QA, and comparison with the companion ChatGPT exporter.

## Examples

| Conversation | Markdown | PDF | What it demonstrates |
| --- | --- | --- | --- |
| Kelp Forests | [Markdown](./kelp-forests.md) | [PDF](./kelp-forests.pdf) | A short essay-style thread with long-form prose and headings. |
| Underground City Design | [Markdown](./underground-city.md) | [PDF](./underground-city.pdf) | A longer conversational thread with multiple turns and visual artifacts. |

## Regenerating

Run the exporter against the saved public-safe snapshot fixtures:

```bash
npm run build
node dist/cli.js --snapshot fixtures/shared-links/plain-text-kelp.snapshot.json --source "https://claude.ai/share/7b2442ee-2ffb-4f82-8852-291840cf5ca0" --out examples/kelp-forests.md --force
node dist/cli.js --snapshot fixtures/shared-links/plain-text-kelp.snapshot.json --source "https://claude.ai/share/7b2442ee-2ffb-4f82-8852-291840cf5ca0" --format pdf --out examples/kelp-forests.pdf --force
node dist/cli.js --snapshot fixtures/shared-links/underground-city.snapshot.json --source "https://claude.ai/share/f750dcac-e458-4228-9b5c-45e3b495aab4" --out examples/underground-city.md --force
node dist/cli.js --snapshot fixtures/shared-links/underground-city.snapshot.json --source "https://claude.ai/share/f750dcac-e458-4228-9b5c-45e3b495aab4" --format pdf --out examples/underground-city.pdf --force
```
